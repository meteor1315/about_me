### Projects and technical contributions

- Personal homelab — Proxmox VE on a Mac mini Intel 2018, with virtual machines, LXC containers and Docker services. Home Assistant OS supports home automation; GNS3 Server supports network simulation. Services include n8n, Nginx Proxy Manager, Tailscaile, Docker, Portainer, Homelab-Hub, MySQL, InfluxDB and Qdrant.
  
- Remote Home Assistant access — Within the Tailscale VPN gateway setup, a reverse proxy provides access outside the local network through the Home Assistant mobile app and a web browser.
  
- Local AI — A MacBook Pro M3 Pro acts as an inference workstation using Ollama and vLLM-MLX. Local models are integrated into n8n through an OpenAI-compatible API, with Qdrant for vector-based applications.
  
- n8n automation — API integrations, JavaScript processing, error handling and retries, Telegram reports, web collection and RAG pipelines, SSH execution of Python scripts and Excel reporting. Portfolio examples include Solana/Jito monitoring and AI Grant Hunter.
  
- Raspberry Pi remote maintenance — A separate Debian headless gateway for a third-party network, using Tailscale subnet routing and Raspberry Pi Connect. Network scanner troubleshooting included service discovery and SANE xerox_mfp configuration following an AirScan incompatibility.
  
- Grandparents home network — Installation and configuration of a UniFi Cloud Gateway Ultra and U6+ access point, plus Ethernet cable pulling to prepare an upper-floor extension.
